# F1 Telemetry Web

Web de telemetría de Fórmula 1 para visualizar informacion del campeonato.

## Características

- Posiciones
- Campeonato
- Neumaticos
- Pit Stops

## Objetivo

El objetivo del proyecto es mostrar datos de telemetría de Fórmula 1 de forma visual e interactiva.
