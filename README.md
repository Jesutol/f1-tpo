# F1 Telemetry Web

Web de telemetría de Fórmula 1 para visualizar datos de rendimiento de los autos y pilotos.

## Características

- Visualización de telemetría
- Datos de velocidad
- RPM
- Marchas
- Acelerador y freno
- Comparación entre pilotos
- Gráficos de vueltas


## Objetivo

El objetivo del proyecto es mostrar datos de telemetría de Fórmula 1 de forma visual e interactiva.
